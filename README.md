# Reflect Magic Mirror

Reflect is a smart mirror app made with Electron, Three.js, and MediaPipe. It has a portrait display, voice assistant, camera effects, video, and music.

Install Node.js 20 or newer, then run:

```bash
npm install
npm start
```

The app opens in demo mode without an API key. Add a Gemini key in Settings to use live voice chat. A webcam is needed for camera effects and tracking.
